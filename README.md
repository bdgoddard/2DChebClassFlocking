Code to implement the numerical results in https://arxiv.org/abs/2603.18185

To start, run AddPaths to ensure that all files are on the MATLAB path.

Figure 1 can be recreated using Projects/Flocking/sweepCriticalGammaF.m

Figures 2-5 can be recreated using Projects/Flocking/Flocking2DIntegralTest.m

Figures 6 and 7 can be recreated using Projects/Flocking/26022026.ipynb

This code is heavily based on 2DChebClass (https://github.com/bdgoddard/2DChebClass)
